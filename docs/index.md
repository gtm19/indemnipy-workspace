# indemnipy

**indemnipy** is a collection of Python packages for working with insurance data.

Built on the modern Python data stack, indemnipy provides practical tooling for the realities of insurance work: messy Excel files, actuarial tables, and AI-assisted analysis.

## Packages

### [indemnipy-ai](indemnipy-ai/overview.md)

pydantic-ai Capabilities for working with insurance data. Gives agents the ability to load, inspect, query, and derive tables from Excel workbooks.
